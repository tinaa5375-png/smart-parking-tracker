# Smart Parking

פרויקט לימודי המדגים מערכת חניה עם שני שרתי Web נפרדים הפועלים באמצעות Docker Compose.

## מבנה הפרויקט

```text
smart-parking/
├── docker-compose.yml
├── README.md
├── web/
│   └── index.html
└── storage/
    └── images/
        ├── car1.svg
        ├── car2.svg
        ├── car3.svg
        └── car4.svg
```

## השירותים

- **web – Nginx:** מציג את לוח הבקרה בעברית בפורט `8080`.
- **storage – Apache HTTP Server:** מספק את תמונות הרכבים בפורט `8081`.
- שני השירותים מחוברים לרשת Docker משותפת בשם `parking-net`.

## דרישות מקדימות

יש להתקין Docker Desktop (או Docker Engine עם Docker Compose) ולהפעיל אותו לפני ההרצה.

## הפעלה

מתוך תיקיית `smart-parking` מריצים:

```bash
docker compose up -d
```

פותחים בדפדפן:

- לוח הבקרה: http://localhost:8080
- בדיקת שרת התמונות: http://localhost:8081/images/car1.svg

## עצירה

```bash
docker compose down
```

## הצגה ממחשב אחר באותה רשת

1. מפעילים את Docker במחשב שמארח את הפרויקט ומריצים את הפקודה.
2. מוודאים שמחשבים אחרים יכולים להגיע אליו ברשת ושחומת האש מאפשרת כניסה לפורטים `8080` ו־`8081`.
3. במחשב המציג פותחים `http://כתובת-ה-IP-של-השרת:8080`.

הדף משתמש בשם המארח שממנו הוא נטען כדי לבנות את כתובות התמונות, ולכן אין צורך לערוך ידנית את `localhost`.

## איך זה עובד?

כאשר המשתמש פותח את לוח הבקרה, הדפדפן מקבל את קובץ `index.html` משרת Nginx. לאחר מכן הדפדפן מבקש את תמונות הרכבים משרת Apache. כך ניתן להדגים שני שירותים נפרדים, שני פורטים ורשת Docker משותפת.

## הערה

נתוני הרכבים ותמונות הרכבים הם נתוני דוגמה לצורכי הדגמה בלבד. אין בפרויקט חיבור למסד נתונים או זיהוי לוחיות רישוי בזמן אמת.
